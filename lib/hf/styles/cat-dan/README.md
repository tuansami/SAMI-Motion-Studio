# Phong cách: Tư liệu cắt dán giấy

Bìa các-tông, giấy xé, chữ cắt từ báo, băng dính, nét bút đỏ. Hợp video kể chuyện, tư liệu, mùa lễ.

Base: `paper` (khuôn dùng bố cục kiểu paper). Chuẩn: `docs/TEMPLATE_STANDARD.md` mục Phong cách.

- [ ] Màu: nền, chữ, nhấn (đủ tương phản trên 9:16)
- [ ] Font: tiêu đề, chữ thường, chữ tay (có trong @fontsource, đủ dấu tiếng Việt và tiếng Đức)
- [ ] Thành phần: thẻ, nút, nhãn, ảnh, nhấn mạnh (em.hl)
- [ ] Kết cấu: hạt, giấy, đường kẻ (tĩnh, không phụ thuộc thời gian)
- [ ] Chuyển động: easing, tốc độ, cách vào / ra (style.js nếu khác mặc định)
- [ ] Âm thanh: bộ SFX gợi ý, kiểu nhạc
- [ ] `node tools/style-new.mjs cat-dan --demo` → xem ảnh bìa `templates/style-cat-dan/preview/`
