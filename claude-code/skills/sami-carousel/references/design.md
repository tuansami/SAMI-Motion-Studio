# Design grammar

**Layout (1080×1350, 72 px margin):** topbar y 64 (series · counter) → hairline y 116 → kicker y ~196 (mono, accent) → BIG WORD y ~250 (900 weight, uppercase, fitted to 936 px, ends with a period or "?") → small line y ~520 (500 weight, `*one word*` highlighted) → demo zone y 690–1110 → triplet bottom-left + Swipe pill bottom-right → progress line bottom 64.

**Copy patterns (DE market):**
- Hook: name the problem in ≤ 4 words and flip it ("Unsichtbar?", "Leere Tische?"). Small line promises the payoff ("3 Hebel, damit Gäste dich *zuerst* finden.").
- Value slide: ONE rule, BIG WORD = the rule's keyword ("Fotos.", "Antworten."), small line = the how, demo = proof by motion.
- CTA: keyword comment ("Kommentiere *MAPS* …") + handle. Never invent numbers, prices, reviews. Fictional restaurant examples: say so in the caption.

**Motion:** one protagonist, one big moment ("hit") per slide on a beat (1.0 / 2.0 / 3.0 s), everything else small. Exits right at ~4.9 s, next slide enters from the left at the same height. Letters react to landings (kick, ≤ 0.2). Grid ripples from impacts. Settle before the loop point.

**Sound:** groove intensity 0.6–0.8 under busy passages; a sound on every visual hit (thump/boop on landings, whoosh on moves, chime/notification for "done", impact + sparkle for the CTA). Gains −6 to −14 dB.

**Themes:** `sami` default for SAMI posts; `cream` for light/editorial; `tomato` for food; `forest` for calm/premium; `noir` for tech/serious. Client posts: set `brand.colors` (navy/mint/purple keys) to the client palette.
